# Ad Optimizer 浏览器插件（Chrome / Edge · Manifest V3）

拖入广告后台导出的 CSV，本地累积去重，自动对比周期波动并给出归因结论与调整建议。

## 防封设计（零风险）

- **不申请任何对 facebook.com / google.com / tiktok.com 的权限**，不注入内容脚本、不爬后台、不做任何自动化操作。对广告平台完全无感知 → 插件本身不会导致封号。
- 数据只来自你**手动拖入的 CSV**，全部在本地浏览器内计算，**不出本机**（用 `chrome.storage.local` 存储）。

## 安装（加载已解压的扩展程序）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 右上角开启 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本 `extension/` 目录
4. 点工具栏的插件图标 → 打开右侧 **侧边栏**

> 注：桌面浏览器专用。手机端请用 `web/` 里的响应式看板（同一套分析引擎）。

## 用法

- 把每天导出的 CSV **拖进侧边栏**（或点击选择），支持一次多份、Meta/Google/TikTok 混合。
- 数据自动按 `平台|广告|内容ID|地区|日期` **去重累积**，天天拖进来即可，不用再手动拼表。
- 顶部下拉切换**维度**和**指标**，看趋势波动带 + 对比结论 + 调整建议。
- CSV 里若带**内容ID/广告ID**，会自动按**单个广告**建维度。

## 回收(ROI) 归因 —— 单个广告回收变化是 CPM 还是 CPC

当数据带**收入/转化**（如你自己后台的 ROI 数据）时，自动多出一张「回收(ROI) 归因」卡：

- 基于恒等式 `回收(ROAS) = (CTR × CVR × 客单价 × 1000) / CPM` 做对数分解，把回收变化精确拆成：
  - **成本侧**：CPM（竞价）还是 CTR（→推高 CPC）
  - **转化侧**：CVR（转化率）还是客单价
- 直接给出判定，例如「回收 -28%，成本侧 100%，**主要来自 CPM（竞价）**」，
  或「回收 -40%，**转化侧（与流量成本无关）**，主因 CVR」。
- 建议层可结合**目标预算 / 区域投放时段**（`buildReport(rows, config)` 传入），给预算配速与分时建议。

## 数据存储与积累（为未来 ML 打基础）

- 用 **IndexedDB + `unlimitedStorage`** 持久化，容量大、可稳定攒数年数据，仍 100% 本地、不上云。
- 保留**完整每日明细**（全字段），未来训练模型想用什么特征都有。
- **导出**：把全部数据存成 JSON —— 既是备份/换机迁移，也是**以后训练 ML 的数据集**。
- **导入**：从备份 JSON 恢复/合并（同样按维度去重）。
- **清空**：清除本地全部数据（建议先导出备份）。

> ⚠️ 长期积累的数据是核心资产。建议定期点「导出」备份，避免误清浏览器数据丢失。

## 文件

```
extension/
├── manifest.json     # MV3，仅 sidePanel + storage 权限（无平台页面权限）
├── background.js      # 点图标开侧边栏
├── sidepanel.html     # 侧边栏 UI
├── sidepanel.js       # 导入/累积/渲染
└── engine.js          # 分析引擎（由 src/ 的 TS 核心移植，浏览器原生）
```

（可选）补一套 16/48/128 png 图标并在 manifest 加 `"icons"` 字段；不加则用浏览器默认图标。
